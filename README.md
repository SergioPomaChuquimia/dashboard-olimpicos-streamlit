# Dashboard Olímpicos con Streamlit

## ¿De qué trata este proyecto?

Aplicación web para visualizar y analizar datos de los Juegos Olímpicos. Incluye gráficos de medallas por país, mapas interactivos con la distribución geográfica de participantes y heatmaps de correlación entre los atributos físicos de los atletas.

## Tecnologías utilizadas

- **Python** — lenguaje principal
- **Streamlit** — interfaz web interactiva
- **Pandas / NumPy** — análisis de datos
- **Matplotlib / Seaborn** — gráficos
- **Folium** — mapas interactivos
- **Pydeck** — visualizaciones 3D
- **Squarify** — treemaps

## Datasets

- `athlete_events.csv` — resultados históricos de los Juegos Olímpicos
- `Tokyo 2021 dataset v4.csv` — datos específicos de Tokio 2021
